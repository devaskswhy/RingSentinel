Before you record

You confirmed you're demoing on the live link, not localhost. These apply to that setup.

  • Warm the live site 60 seconds before you roll — open ringsentinel.onrender.com/clusters in a tab. Render's free tier sleeps after ~15 minutes idle; a cold wake mid-take is up to a minute of dead air. It was warm when checked (0.36s response) — that can change by the time you actually record.
  • Never click "generate case file" live. Case-file generation is disabled on the deployed backend by design (confirmed: returns 503) — the licensing terms of the Agent SDK don't allow serving other users on a personal subscription. Every cluster already has a case file; just open one.
  • Approving/dismissing on the live link is real and permanent. It writes to the public database. Decide in advance which cluster you'll approve — the script below uses 796aedb1…, score 0.837, confirmed still pending with a case file already generated.
  • Mute notifications, close anything with a badge counter, hide the bookmarks bar.

We built the obvious fix, it made real families worse, so we shipped it off."
